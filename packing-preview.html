每日穿搭建議

以舒適、防曬和拍照效果為主；峇里島炎熱潮濕，盡量選亞麻、棉質或快乾布料。

DAY 18/28

搭機抵達＋Kuta 晚餐

台北 → 峇里島 → YELLO Hotel

穿：寬鬆短袖、薄長褲、好穿脫的運動鞋；機上加薄外套。

顏色：米白、淺灰、霧藍

不需泳裝
DAY 28/29

海神廟＋Ubud 寺廟與梯田

Tanah Lot → 藝術村 → 梯田 → 聖泉寺 → Villa

穿：透氣上衣＋過膝長裙或薄長褲，搭防滑好走涼鞋。寺廟避免過度裸露。

顏色：白、燕麥、橄欖綠；和梯田、寺廟最搭

Villa 泳池需要泳裝
DAY 38/30

上午泛舟＋下午 ATV＋Villa

上午泛舟 → 下午 ATV → 返回 Villa 休息

泛舟穿：排汗衫或快乾短袖、運動短褲或防潑水褲，搭有鞋帶的水陸兩用鞋；另外帶一套乾衣服。

部位不要穿建議穿
上衣泳衣上衣、棉 T、長袖襯衫排汗衫、快乾短袖
下身牛仔褲、長裙運動短褲、防潑水褲
鞋子拖鞋、一般涼鞋水陸兩用鞋、有鞋帶

顏色：黑、深綠、咖啡；泥巴與水漬較不明顯

泳裝只留給 Villa 泳池
DAY 48/31

03:00 日出吉普車＋瀑布＋AYANA

03:00 Mount Batur 日出 → 瀑布（拍照散步，不下水）→ AYANA

穿：日出時短袖外加薄外套與長褲；白天可換輕便上衣，鞋子需防滑。

顏色：磚紅、焦糖、奶油白；日出與火山背景突出

泳裝給 Villa／AYANA 使用
DAY 59/01

AYANA 渡假村放鬆

泳池、沙灘、Rock Bar

穿：泳裝外搭罩衫或亞麻襯衫；傍晚換度假洋裝／襯衫短褲與好走涼鞋。

顏色：白、珊瑚橘、寶藍；海景與夕陽都亮眼

一定要帶泳裝
DAY 69/02

Melasti Beach＋Uluwatu

懸崖公路 → 海灘午餐 → 烏魯瓦圖 → Sanur

穿：海灘可穿泳裝加罩衫；去寺廟前換乾爽衣服與過膝下身，搭涼鞋。

顏色：純白、沙色、天空藍；懸崖與海景照片最乾淨

想在 Melasti 下水就帶
DAY 79/03

跳島／浮潛＋Coco Bistro＋ICON BALI

Sanur 碼頭 → 離島活動 → 海濱晚餐 → 商場逛街

穿：泳裝＋長袖防曬水母衣、快乾短褲與水陸鞋；帶乾衣服晚上換。

顏色：亮黃、珊瑚紅、土耳其藍；在海上辨識度高

一定要帶泳裝
DAY 89/04

Sanur 散步＋搭機返程

Sanur → 機場 → 香港轉機

穿：舒適短袖、薄長褲與運動鞋，薄外套放隨身包應付機艙冷氣。

顏色：米色、灰藍、深藍；耐髒又適合長途飛行

不需泳裝
泳裝必帶日Day 2–3 Ubud Villa、Day 4–5 AYANA、Day 7 跳島／浮潛。
泛舟服裝Day 3 穿排汗快乾衣褲與有鞋帶的水陸鞋，不穿泳衣上衣；泳裝留給 Villa。
最萬用配色白色、燕麥色、天空藍，再帶一件亮色泳裝拍海景。
