# 每日交通卡片與車資

資料來源：`public/data/itinerary.js`。Day 2、3、5 的 `quickGuide` 定義編號步驟、提醒、查核日期與官方來源；步驟的 `eventIds` 指向同日事件。

每個交通事件的 `fare.legs` 記錄成人 IC 票價；`fare.adjustments` 記錄轉乘折扣（負數）。`TripCore.fareAmount` 與 `dayFareTotal` 自動加總，畫面四人合計為每人合計乘四。付費交通漏填時，不顯示不完整的每日總額。替代路線、計程車、餐費與門票不加進原定路線合計。
