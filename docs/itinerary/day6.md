# 09:20｜到飯店 Lobby 等免費 Shuttle

## HOTEL MYSTAYS Haneda → 羽田機場

飯店有提供：

> **免費機場接駁車 Free Shuttle Bus**

我們今天的首選：

# **09:30 飯店發車**

### 為什麼選 09:30？

BR191 是 **12:40 起飛**。

長榮羽田 BR191 櫃檯官方規定：

- 起飛前 **2.5 小時**開始報到
- 起飛前 **40 分鐘**停止報到

因此：

```text
12:40 - 2小時30分 = 約10:10 開櫃
12:40 - 40分鐘 = 約12:00 截止報到
```

搭 09:30 Shuttle，大約 09:40 左右抵達 T3，會比長榮櫃檯開櫃稍早。

這樣最舒服：

> 不用趕，也不會早到機場太誇張。

---

# ⚠️ Shuttle 不能預約座位

飯店 Shuttle 是：

> **先到先搭 First come, first served**

不能事先預約。

車輛座位有限，而且四個人還有行李，因此不要 09:29 才從房間跑下來。

## 建議

**09:20 前就在 1F Lobby 等。**

如果櫃台有指定集合位置，照櫃台指示。
