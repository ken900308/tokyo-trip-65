# 10:40～10:50｜怎麼找到墨田水族館入口

墨田水族館的正式入口在：

**Tokyo Solamachi 5F**

最容易記的方法：

1. 進入 Tokyo Solamachi
2. 跟著館內 **「すみだ水族館 / Sumida Aquarium」** 指標
3. 前往 **West Yard / ウエストヤード**
4. 到 **4F 戶外區**
5. 使用「水族館專用電梯」或手扶梯
6. 上到 **5F Entrance**

官方特別標示：

> 水族館入口在 5F，West Yard 4F 戶外區設有水族館專用電梯與手扶梯。

### 長輩版

# 上野站出哪個出口？

## 最直接：5b

東京 Metro 官方出口資訊直接寫：

**5b → Ameyoko / アメ横**

所以一般情況：

**上野 G16 → Exit 5b**

出來就是阿美橫町附近。

---

## 長輩需要電梯：5a

**5a 有地面電梯。**

所以：

- 可以走樓梯 → **5b**
- 需要電梯 → **5a**

5a、5b 都在阿美橫町這一側，不需要繞到 JR 上野站公園口。

# 進入阿美橫町

**上野站 Exit 5b**

直接開始。

**Exit 5a**

---

# 逛街方向

**上野**
↓  
**阿美橫主街**
↓  
慢慢逛
↓  
**御徒町**

不用特別把每一條支線逛完。

有長輩同行：

看到想逛的店再進即可。

---

# 為什麼不要太晚才開始逛

阿美橫沒有統一營業時間。

官方店家資料可以看到：

很多店約在：

**18:30～20:00**

之間陸續關門。

因此：

**17:00 左右抵達最好。**

19:30 左右就可以準備回住宿。

---

# 阿美橫逛累了怎麼辦？

如果已經走到御徒町那端：

不用走回 JR 上野站。

附近有：

- JR 御徒町站
- 東京 Metro 上野廣小路站 G15
- 都營大江戶線 上野御徒町站

這也是為什麼建議：

**上野端進、御徒町端出。**

# Plan B｜四個人都累了：直接搭計程車

**4～5 km**

尤其：

- 長輩已經走了一整天
- 買了很多東西
- 不想再轉車

直接把住宿地址給司機：

**東京都墨田区業平5丁目1-8**

即可。

---

# 另一個免轉車備案｜都營巴士 上23

上野一帶另有：

**都營巴士 上23**

可從：

**上野松坂屋前**

往押上方向。

途中會經過：

**押上**

優點：

- 不用轉車
- 有座位就很輕鬆

缺點：

- 巴士班距與路況變數較大
- 不適合當固定主方案

所以：

**剛好看到車 → 可以搭**
**沒有 → 不用等，搭電車或計程車**
